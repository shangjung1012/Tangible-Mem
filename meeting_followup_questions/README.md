# Meeting Follow-up Questions

這個資料夾提供每場會議（Bmr001~Bmr031）結束後可直接提問的清單，分為：
- 當次會議提及可追問
- 跟之前會議相關的延續追問

資料來源：`ICSI_original_transcripts/transcripts/*.mrt`。
若某場逐字稿缺失，檔案會標示 `transcript_status: missing`。

## 怎麼問最能吃到記憶

- 問短期（最近進度 / TODO / owner）：明確寫「最近」、「目前」、「這週」、「待辦」、「負責人」。
- 問長期（演進 / 因果 / 為何改法）：明確寫「從 BmrXXX 到 BmrYYY」、「演進」、「為什麼改」、「取捨」。
- 盡量帶關鍵詞：方法名、任務名、會議編號（例如 `Bmr023`）、指標名。
- 問題可加輸出格式：例如「請列 3 點，含決策、理由、下一步」。
- 單輪想同時吃短+長記憶，可用：`先給最近三次狀態，再補半年演進脈絡。`

### 可直接套用的句型

- `目前和 <topic> 相關的待辦有哪些？各自 owner、狀態、下一步是什麼？`
- `從 Bmr0XX 到 Bmr0YY，<topic> 的方法怎麼演進？每次改動理由是什麼？`
- `上次提到的 <issue> 在這次會議有沒有被解掉？如果沒有，現在阻礙是什麼？`
- `請把 <topic> 的決策鏈整理成：決策 → 證據 → 風險 → 下次驗證。`
