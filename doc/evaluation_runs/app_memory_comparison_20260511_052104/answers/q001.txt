根據提供的資料，關於 long-term memory 的檢索運作方式與其架構設計，目前有以下幾個重點：

*   **利用時間軸進行版本比較**：理論上，在檢索 long-term memory 的資訊時，系統能提供一個時間線索。這讓大型語言模型（LLM）可以利用時間戳來識別相似的論點，觀察哪些舊論點已被推翻，並採納最新的版本。(來源: L1-0422-037)

*   **引入「遺忘」與「時間衰減」機制**：
    *   long-term memory 的一個關鍵設計是「遺忘」機制，資訊的關聯性和重要性會隨時間衰減，這是它與 short-term memory 的主要區別之一。(來源: L1-0422-039, L1-0422-031)
    *   為了處理主題的重現，系統採用了時間衰減機制。記憶節點的「recency」（新近度）分數會隨時間下降，但會根據其初始的「importance」（重要性）分數設定一個最低下限值，以確保重要的舊資訊不會完全消失。(來源: L1-0408-007)

*   **整體的檢索優化策略**：
    *   整個記憶系統採用了階層式資料結構（idea units -> segments -> topics）以及雙標籤策略（功能標籤與主題標籤）來優化檢索。不過，關於標籤的最佳搜尋優先順序仍在討論中。(來源: S001)
    *   專案的核心挑戰之一，便是研究 agent 應如何權衡與組合來自工作、短期和長期三種記憶體的資訊，以生成最佳輸出。(來源: L1-0325-056)
