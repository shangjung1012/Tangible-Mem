根據提供的資料，團隊針對記憶評估策略（memory evaluation strategy）討論過以下幾個方向：

### 1. 評估方法與比較基準
*   **消融研究 (Ablation Study)**：決定進行一項研究，比較完整系統與幾個基準線（僅 RAG、僅短期記憶、僅長期記憶）的表現，以評估各元件的貢獻。(來源: 0429 / L1-0429-048)
*   **比較不同的分塊 (Chunking) 策略**：決定採用兩階段評估，首先會比較「動態分塊」與「固定大小分塊」、「逐句分塊」等基線方法的成效。(來源: 0422 / L1-0422-020, 0429 / L1-0429-065)
*   **評估資訊遺忘機制**：計畫透過 demo 來展示 agent 如何因其遺忘機制（如 "fade-out"）能正確忽略過時資訊，並證明其優於標準 RAG 模型。(來源: 0422 / L1-0422-043, 0429 / L1-0429-037)
*   **參考外部論文**：在初期曾建議研究參考論文如何評估其模型，以應對評估這項關鍵挑戰。(來源: L2-evaluation-datasets-ground-truth / L1-0307-023)

### 2. 評估問題的類型與定義
*   **三種核心問題類型**：提出一個包含三類問題的評估計畫：
    1.  **短期問題**：測試即時上下文的準確性。
    2.  **長期演變問題**：追蹤主題在多次會議中的歷史變化。
    3.  **決策推理問題**：解釋過去決策的理由。
    (來源: 0429 / L1-0429-038)
*   **推理類型定義**：定義了「single-hop」（直接問答）和「multi-hop」（需要解決中間子問題的複雜問題）推理，以進行更細緻的評估。(來源: L2-evaluation-datasets-ground-truth / L1-0318-011, L1-0318-009)
*   **無法回答的問題**：曾討論是否應包含一項測試，用於識別 agent 知識範圍之外無法回答的問題，此想法源於 LOCOMO 資料集。(來源: L2-evaluation-datasets-ground-truth / L1-0318-001)

### 3. 評分標準與資料集
*   **以 LLM 作為裁判**：確定將使用一個預先定義的「標準答案」(ground truth)，並利用 LLM 來比較 agent 生成的答案與標準答案的正確性，進行二元（正確/不正確）評分。(來源: 0429 / L1-0429-039, L2-evaluation-datasets-ground-truth / L1-0318-013)
*   **資料集限制**：注意到目前的會議資料集時間跨度可能太短，不利於有效展示資訊遺忘等長期記憶功能。(來源: 0422 / L1-0422-043)
