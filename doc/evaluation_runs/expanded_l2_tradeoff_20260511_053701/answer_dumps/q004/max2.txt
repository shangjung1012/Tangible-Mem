根據提供的資料，關於記憶評估策略（memory evaluation strategy）曾討論過以下幾個方向：

1.  **兩階段評估策略**：曾提出一個包含兩部分的評估策略。第一部分是將專案的動態分塊方法與固定大小、逐句分塊等基線方法進行比較；第二部分是將專案的結構化記憶系統與標準的 RAG 模型進行比較 (meeting_id: 2026-04-22, obj_id: L1-0422-022)。

2.  **與 RAG 模型的比較**：多次提到可以透過與標準 RAG 模型比較來展示記憶模型的價值。具備遺忘機制的 agent 應能正確忽略過時資訊，展現其對主題生命週期的理解，這是標準 RAG 模型所缺乏的能力 (meeting_id: 2026-04-22, obj_id: L1-0422-045)。完整系統的優勢在於它會先將逐字稿結構化為「idea units」，而不僅僅是進行文本分塊和語義搜索 (meeting_id: 2026-04-29, obj_id: L1-0429-019)。

3.  **消融研究 (Ablation Study)**：決定進行一項消融研究來評估系統。該研究將比較完整系統與幾個基準線的表現，包括：僅 RAG、僅短期記憶、僅長期記憶 (meeting_id: 2026-04-29, obj_id: L1-0429-048; L2-overall-memory-system-evaluation)。

4.  **評估「淡出 (fade-out)」機制**：決定導入並評估一種「淡出」機制。此機制透過為每個記憶項目設定「重要性分數」來運作，分數低的資訊在一般對話中會被抑制，但若被反覆提及則分數會提升 (meeting_id: 2026-04-29, obj_id: L1-0429-037)。
