根據提供的資料，manager-agent 架構是從目前的單體式腳本（monolithic script）演變而來的。

這次架構轉變的核心是為了實現「關注點分離」（separation of concerns）。在新的模型中，一個中央的精簡 manager 會依序協調多個小型的專業 agent，每個 agent 都是特定任務的專家（例如計算跳行、更新記憶體等），而 manager 的職責則簡化為僅分派任務給這些 agent。

這個演變的動機之一是，目前的實作中，「管理者」也承擔了過多細微的 agent 類任務，因此決定進行重構，以更符合 manager-agent 的架構精神。
