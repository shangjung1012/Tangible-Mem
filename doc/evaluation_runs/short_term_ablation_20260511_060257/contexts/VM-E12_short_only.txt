[S023] LTM Architecture: Time-Based vs. Topic-Based Hierarchical Models, Three-Tier Structure, and L2/L3 for Temporal Context
  score: 2.25
  summary: The long-term memory (LTM) system's architecture presents a key difference in handling recurring topics between time-based and topic-based models. The time-based model creates new L1 nodes for each mention to preserve chronological order, whereas the topic-based model updates existing L1 nodes to build an evolutionary history within a single node. This architectural debate is further contextualized by a proposed three-tier hierarchical structure (L1, L2, L3), designed to manage fine-grained ideas from single meetings (L1), summarize L1s from blocks of meetings (L2), and provide high-level summaries (L3), influencing how revisited topics are managed. For time-oriented memory structures, retrieval should provide matching L1 units along with their L2/L3 parent nodes to furnish large language models with essential temporal context, an approach influenced by the TiM paper to facilitate the extraction of chronological context.
