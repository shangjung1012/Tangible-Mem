# Tangible Mem Pilot Task Packet

Use this packet with the Memory Observatory interface. Each task should be run
with the same dataset and query set for all participants.

## Task 1: Retrieval Trace Inspection

Open the Retrieval Trace for the ICSI audio-processing carryover query.

Answer:

- Which L1 evidence seeds were retrieved?
- Which evidence item is the strongest source for the answer?
- Did the L2 / child-L2 Evolution Context add cross-meeting context, or did it
  add noise?
- Which selected events were shown, and which omitted events would you want to
  inspect next?

## Task 2: Topic Observatory Review

Open Topic Observatory and inspect the topic family related to audio acquisition
or recording setup.

Answer:

- Is the L3 topic family useful as navigation?
- Are the child L2 labels understandable?
- Does one child L2 look too broad, too narrow, or incorrectly labeled?
- Which linked L1 object would you inspect first to verify the topic?

## Task 3: Memory Explorer Evidence Check

Open Memory Explorer and select one L1 object used by the trace.

Answer:

- Does the L1 content match its evidence?
- Is the importance reasonable?
- Is the topic link reasonable?
- Would you trust this object as source evidence for an answer?

## Task 4: Correction Review

Use Correction Review to decide which sidecar correction should be recorded.

Choose one:

- Importance override: the object is more or less important than its canonical
  score.
- Summary correction: the effective summary should be clearer, narrower, or
  broader.
- Validity flag: the object is outdated, duplicate, unsupported, or low-value.
- Topic-link review: the object is assigned to the wrong topic, needs a new
  topic, or should have a link removed.

Record:

- selected correction type
- reason
- expected effect on the effective memory view
- whether raw L1 evidence should remain unchanged

## Task 5: Reflection

Answer:

- What did the interface make easier to inspect?
- What remained confusing?
- Would the sidecar correction workflow be enough for your own research meeting
  records, or would you need direct raw editing?
