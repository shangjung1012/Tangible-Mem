Tangible Mem

Long-term meeting memory as inspectable layers

Instead of hiding memory inside full transcripts or flat retrieved chunks, Tangible Mem turns meeting history into evidence cards, topic states, navigation families, and correction sidecars.

Core interaction

Users inspect what was remembered, why it was retrieved, which topic context was added, and how the effective memory should be corrected without overwriting source evidence.
