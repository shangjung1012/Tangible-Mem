Memory Observatory

Inspectable Layered Memory Pipeline

The system does not treat transcripts as opaque retrieval chunks. It turns meeting evidence into inspectable L1 objects, organizes them into topic context, and exposes both retrieval traces and non-destructive correction sidecars.
