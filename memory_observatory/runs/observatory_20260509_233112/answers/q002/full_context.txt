根據提供的資料，manager-agent 的架構是為了解決一個處理長文本的系統中所遇到的問題而提出的。

這個概念的演變過程如下：

1.  **初始架構**：一個處理長文本的系統會將文章切分成許多小區塊（chunks），並讓每一個 agent 依序（sequentially）處理一個區塊。後一個 agent 會讀取前一個 agent 處理完的內容，再繼續處理自己的部分 (meeting 0318 / line 3-7)。
2.  **發現問題**：這種作法產生一個問題，因為每個 agent 都只擁有自己區塊的資訊以及前一個 agent 傳來的摘要，缺乏對整個文本的「全域理解」（global understanding）(meeting 0318 / line 10-13)。
3.  **提出解決方案**：為了克服這個限制，有人提出應該要有一個「共享黑板」（shared blackboard），讓所有 agent 都能存取，以建立全域的理解 (meeting 0318 / line 12-13)。
4.  **Manager-agent 的角色**：在這個架構下，最後會有一個 **manager agent**，它的作用就是接收並整合所有 worker agent 處理完的資訊，以進行最終的任務，例如回答問題 (meeting 0318 / line 18-22)。
