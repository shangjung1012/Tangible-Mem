根據提供的資料，將 transcript 拆分成 segment 或 idea units 的主要原因如下：

1.  **提升大型語言模型（LLM）的處理精準度**：過去的經驗顯示，如果將整份很長的逐字稿直接丟給 LLM 處理，會導致標記效果不佳、不準確，甚至出現幻覺（hallucinate），也就是模型會產生內容中不存在的東西。將逐字稿切成較小的單位（如 idea unit），可以減少每次處理的上下文，有助於讓產生的內容更精準 (meeting: 0408, lines: 52-60)。

2.  **建立標準化的前處理流程**：與其將整份內容當作一個黑盒子直接丟進去處理，不如先進行前處理。將逐字稿切成 idea units 或更小的單位（例如按句點或發言輪次切分），被視為一個必要的處理步驟，可以讓後續的分析（如下標籤）更有條理 (meeting: 0408, lines: 60-65)。

3.  **實現更可控的處理流程**：將逐字稿拆分後，可以對每一個 idea unit 進行獨立的、結構化的處理。例如，可以依序處理每個 idea unit，並決定是否要更新記憶體。這種作法讓整個流程的步驟更加清晰且可控，而不是讓模型自行決定要不要更新 (meeting: 0429, lines: 287-290)。在 Manager-Agent 的架構下，拆分 idea units 可以被視為一個獨立的任務，由特定的 agent 處理，讓整個工作流程更清晰 (meeting: 0429, lines: 316-322)。
