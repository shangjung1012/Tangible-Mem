好的，根據您提供的會議記錄，目前 memory node 的分數設計包含 importance、activation、recency 和 relevance，各自負責不同的功能。

詳細說明如下：

### 1. Importance (重要性)
`Importance` 是在 memory node (L1 idea unit) 建立時就被賦予的一個靜態分數，代表該節點在「被建立的當下」有多重要。

*   **計算方式**:
    *   主要由 LLM 根據預設的準則來判斷並賦值，沒有預設值 (rag-0506-L46-L65)。
    *   在同一次會議中，如果某個觀點 (viewpoint) 被頻繁提及，相關的 idea units 的 `importance` 都會被加成 (rag-0506-L46-L65)。
*   **特性**:
    *   **靜態的**: 一旦設定後，系統本身不會因為時間流逝而改變它。這麼做是為了保留其作為「最初建立時，這個想法好不好的一個指標」的參考價值 (rag-0506-L46-L65)。
    *   **可由使用者調整**: 有一個重要的設計方向是，允許使用者手動調整 `importance` 的權重。例如，當使用者認為某個節點很重要但 LLM 判定不重要時，可以手動提高其 `importance`。系統甚至可以基於相似性，推薦使用者將相關節點的 `importance` 一併調高 (rag-0506-L46-L65)。
*   **作用**:
    *   `importance` 會影響記憶的衰退。如果一個節點的 `importance` 很高，它會有一個「下限 (floor)」，確保它不會因為時間久遠而被完全遺忘或衰退到太低 (rag-0506-L46-L65)。
    *   如果使用者手動調高過 `importance`，該節點在長期記憶中的衰退速度 (decay) 會比其他節點慢 (rag-0506-L46-L65)。

### 2. Activation (活躍度)
`Activation` 是一個獨立於 `importance` 的參數，用來判斷「這個記憶現在有多活躍」。

*   **目的**: 團隊不希望因為時間衰退而直接修改 `importance`，以免失去其原始的參考價值。因此，引入 `activation` 這個參數來專門處理記憶的「活躍」與「衰退」 (rag-0506-L46-L65)。
*   **作用**: `activation` 的值會隨著時間（由 `recency` 影響）而衰減，代表記憶的「時效性」。

### 3. Recency (新近度)
`Recency` 是與時間相關的分數，反映了一個節點被提及的新近程度。

*   **計算方式**:
    *   新會議產生的節點 `recency` 分數最高 (rag-0506-L61-L72)。
    *   隨著時間推移或新會議的發生，舊節點的 `recency` 分數會衰減 (decay) (rag-0506-L61-L72)。
    *   如果一個舊的 L1 節點在新的會議中被再次提及並更新，它的 `recency` 會被重新拉高 (rag-0506-L61-L72)。
*   **作用**: `recency` 是影響 `activation` 分數衰退的主要因素。

### 4. Relevance (相關性)
`Relevance` 與前三者不同，它不是儲存在節點上的固定分數，而是在「檢索 (retrieve)」時動態計算的。

*   **計算方式**:
    *   在檢索階段，透過計算使用者查詢（query）與 memory node 內容之間的「語意相似度 (semantic similarity)」來得出 (rag-0506-L46-L65)。
*   **作用**:
    *   `relevance` 主要用於從大量的 memory nodes 中找出與當前需求最相關的記憶。
    *   會議中明確區分了 `relevance`（語意相似度）和 `recency`（時間相似度）是不同的概念 (rag-0506-L46-L65)。

**總結**：
`Importance` 是節點誕生時的內在價值，是靜態的。`Recency` 是時間的標記，會隨時間變化。`Activation` 是節點當前的活躍程度，會受到 `recency` 的影響而衰退，但衰退程度會被 `importance` 的下限所保護。`Relevance` 則是在需要提取記憶時，根據當前情境動態計算的語意匹配度。
