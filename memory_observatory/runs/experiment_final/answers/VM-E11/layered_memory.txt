好的，這是一個關於長期記憶體（Long-term memory）架構演進的說明。

長期記憶體架構的演進是為了解決在跨越多場會議的記憶中，如何平衡時序脈絡的清晰度、主題演進的追蹤、以及資訊的衰減與保留等問題。其演變過程大致如下：

### 第一階段：從分離的短/長期記憶體概念出發

專案最初的記憶體架構包含工作記憶（Working Memory）、短期記憶（Short-Term Memory, STM）和長期記憶（Long-Term Memory, LTM）三個部分（**[0325 | L1-0325-036]**）。

然而，團隊很快就意識到一個簡單的「短期記憶淡忘後移入長期記憶」模型存在問題。如果一個主題持續演進，最新的進展（例如 C 和 D）還在短期記憶中，那麼長期記憶將會停留在舊的狀態（例如 A 和 B），無法反映專案的最新情況（**[0408 | L1-0408-043]**）。

為了解決這個問題，團隊決定讓**短期和長期記憶體獨立更新**（**[0408 | L1-0408-036]**），兩者會各自接收完整的會議內容進行處理，而不會有直接的資訊流動（**[0422 | L1-0422-010]**）。保留短期記憶的理由是它能捕捉近期對話中更詳細、更瑣碎的細節，而這些細節在更為摘要式的長期記憶中可能會遺失（**[0422 | L1-0422-036]**）。

### 第二階段：轉向結構化的「想法單元」與複雜的遺忘機制

為了更有效地組織資訊，系統不再只是簡單地對文本進行分塊，而是將逐字稿結構化為「**想法單元 (idea units)**」，這成為記憶體的基本物件（**[0429 | L1-0429-019]**）。

同時，為了處理記憶的保留與遺忘，團隊設計了更複雜的機制，而不僅僅是基於時間。
1.  **早期概念**：團隊早期就意識到，純粹的樹狀結構會打散時間維度，不適合實現基於時間的權重衰減（**[0325 | L1-0325-049]**）。
2.  **引入多維度評估**：一個想法的重要性（例如由討論密度決定）應使其能留存在長期記憶中，即使它已經很舊（**[0408 | L1-0408-054]**）。為此，系統引入了 `recency`（新近度）和 `importance`（重要性）的概念。`recency` 會隨時間衰減，但會根據其初始 `importance` 分數設定一個最低下限（floor），以防止重要的舊記憶完全消失（**[0408 | L1-0408-007]**）。
3.  **機制優化**：後來，這個機制被進一步優化。團隊決定將 `importance` 分數**保持靜態**，作為節點創建時重要性的歷史參考。而記憶的衰減則由一個獨立的 `activation`（活躍度）參數處理（**[0506 | L1-0506-030]**）。

### 第三階段：L1/L2/L3 層級結構的確立與核心設計辯論

為了在細節和高層次脈絡之間取得平衡，團隊確立了三層級的長期記憶體結構：
*   **L1**：基礎的記憶單元或想法單元（idea units）。
*   **L2**：對 L1 節點的摘要。
*   **L3**：所有上下文的最高層級摘要。
檢索時，系統會先匹配到 L1 的具體細節，然後一併帶出其父層的 L2 和 L3 摘要，從而提供完整的上下文（**[0408 | L1-0408-006]**, **[0422 | L1-0422-025]**, **[0506 | L1-0506-029]**）。

在確立了三層結構後，專案面臨一個關鍵的設計決策：L2 層應該如何組織 L1 單元？
*   **時間導向架構**：此方法主張每個 L2 節點對應一次會議或一個固定的會議區間（例如四次會議）。優點是能保留一個清晰、不可變的時間軸，讓 LLM 容易解讀一個想法在不同會議間的演變脈絡（**[0506 | L1-0506-042]**, **[0506 | L1-0506-044]**）。
*   **主題導向架構**：此方法主張根據語意主題來組織 L1 單元。當一個相似的想法被重新討論時，系統會更新現有的 L1 節點，而不是創建新節點。優點是可以在單一節點內追蹤一個想法的完整演變歷史（**[0506 | L1-0506-045]**）。

### 最新實作狀態 (Latest Implementation State)

根據最新的實作狀態，團隊最終選擇了**以主題為基礎的 L2 分組方式**，同時保留了 L1 的時間不可變性，有效地結合了兩種架構的優點。
*   **L1 來源**：是來自每次會議的、**不可變的**證據（`share_mem/meetings/*.json`），這保留了清晰的時間戳。
*   **L2 活躍視圖**：L2 的分組是**基於主題**的，它組織了來自不同會議的不可變 L1 物件。這解決了追蹤主題演變的需求，並且明確指出**不是**採用四次會議批次或一次會議一個 L2 的時間導向分組。
*   **L3 晉升**：當 L2 的主題家族變得過於龐大時，會被晉升為 L3，以進行更高層次的管理。

總結來說，長期記憶體架構從最初較為模糊的 STM/LTM 分離概念，演變為一個精細的、分層的系統。這個系統以不可變的 L1 想法單元為基礎，保留了時間的準確性；同時在 L2 層級採用主題式聚合，以有效追蹤想法的演進歷史，最終在時間與主題兩種組織維度之間取得了平衡。
