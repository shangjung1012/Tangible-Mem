根據提供的資料，關於評估基準（baseline）與指標（metrics）的設計演進如下：

目前的評估策略主要分為兩部分：一部分是評估文本分割（chunking/segmentation）的效能，另一部分是評估整體記憶系統的表現。

**目前的評估基準與指標：**

1.  **文本分割 (Text Segmentation) 評估**：
    *   **基準 (Baseline)**：將動態分塊（dynamic chunking）方法與固定大小（fixed-size）和逐句（sentence-by-sentence）等方法進行比較 ([L1-0422-020])。
    *   **指標 (Metrics)**：透過建立一個手動標記正確斷點的「真實標記」(ground truth) 資料集，來計算不同方法的精確度（precision）和召回率（recall）([L1-0506-013], [L1-0429-065])。同時也會評估計算成本（以 LLM 請求次數為代理指標）([L1-0429-033])。

2.  **整體記憶系統評估**：
    *   **基準 (Baseline)**：
        *   將專案的結構化記憶系統與標準的 RAG 系統進行比較 ([L1-0422-020])。
        *   另外也曾設定一個「無三層記憶體結構的系統」（相當於輸入完整對話記錄）作為比較基準，但此方法被認為不可行 ([L1-0325-057])。
    *   **指標 (Metrics)**：採用一個三分類問題框架進行評估，並使用 LLM 作為裁判，比對 Agent 生成的答案與預先定義的「標準答案」(ground truth) 的正確性 ([L1-0429-039], [L1-0429-010])。

---

**從 0318 到 0429 的設計演進歷史：**

評估方法的設計是逐步演進的，從早期的概念探討，到後期形成具體的兩階段評估計畫。

1.  **初步概念 (2026-03-07)**：
    團隊意識到評估是關鍵挑戰，應研究參考論文如何評估其模型，尋找可用的資料集或標準化測試 ([L1-0307-028])。

2.  **引入 LLM 作為裁判 (2026-03-18)**：
    在一次論文回顧中，團隊討論了 LOCOMO 論文的策略，即採用 LLM 作為裁判，對答案進行二元（正確/不正確）判斷。這種方法可以避免語義相似度分數可能產生的誤判問題 ([L1-0318-013])。

3.  **定義比較基準 (2026-03-25)**：
    為了證明三層記憶體架構的優越性，團隊決定將「無三層記憶體結構的系統」設定為比較基準（baseline），儘管當時認為將完整對話直接輸入模型是不可行的 ([L1-0325-057])。

4.  **確立兩階段評估策略 (2026-04-22)**：
    評估策略被明確為一個兩階段計畫：
    *   **第一階段**：針對文本分塊（chunking），比較動態分塊與固定大小、逐句等基線方法。
    *   **第二階段**：針對整體系統，將專案的結構化記憶體與標準的 RAG 系統進行比較 ([L1-0422-020])。

5.  **細化評估框架與指標 (2026-04-29)**：
    團隊進一步細化了評估計畫，整合了先前的想法：
    *   **三分類問題框架**：正式提出評估計畫將圍繞三種類型的問題建構：
        1.  **短期正確性** (Short-term correctness)：確保 Agent 不會遺漏或捏造資訊。
        2.  **長期主題演變** (Long-term evolution)：追蹤一個主題在多次會議中的完整演進。
        3.  **決策推理** (Decision reasoning)：解釋過去某個決策背後的原因。
        ([L1-0429-010], [L1-0429-038])。
    *   **結合 Ground Truth 與 LLM 裁判**：確定評分方法將使用預先定義的「標準答案」(ground truth)，並沿用 3 月份討論的想法，利用 LLM 來比較 Agent 答案與標準答案的正確性 ([L1-0429-039])。
    *   **量化分塊指標**：針對分塊實驗，確定將使用**精確率 (precision)** 和 **召回率 (recall)** 作為指標，並以人類定義的「重要 idea units」作為 ground truth 進行比對 ([L1-0429-072], [L1-0429-065])。
    *   **計畫延期**：不過，團隊也決定推遲原定比較三種文本分塊策略的實驗，待 5 月 12 日報告後再進行 ([L1-0429-023])。

6.  **最新進展 (2026-05-06)**：
    最新的討論再次確認了評估文本分割（segmentation）效能的方法，決定要建立一個手動標記正確斷點的「真實標記」(ground truth) 資料集，以客觀計算精確度與召回率 ([L1-0506-013])。這表明先前於 4 月 29 日規劃的評估方法仍在持續推動。
