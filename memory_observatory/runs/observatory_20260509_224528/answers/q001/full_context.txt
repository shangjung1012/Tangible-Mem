根據提供的資料，在會議中討論到一篇 2024 年的論文，其處理長篇文章（Long Context）的做法是將文章切分成多個「chunks」（區塊）。

這個做法的目的是：
1.  **分工處理**：將長文切分後，每一個 agent 負責處理一個 chunk 的摘要（summary）。
2.  **循序處理**：這些 agent 是循序（sequentially）工作的。第一個 agent 完成摘要後，會將結果傳遞給第二個 agent。第二個 agent 在處理自己負責的 chunk 時，也需要讀取前一個 agent 傳來的資訊，以此類推。

不過，會議中也提到這種切分方式的潛在問題，例如：如果切分方式很隨機（例如按固定句數切分），可能會將一句話從中間切斷，導致 agent 無法完整理解語意。
