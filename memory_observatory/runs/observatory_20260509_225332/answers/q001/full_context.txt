根據提供的資料，會議中曾討論過一篇2024年的論文，其處理長文（Long Context）的方式，是將長篇文章切分成數個 `chunks`，再讓每一個 agent 負責一個 `chunk` 的摘要。這麼做的目的是為了處理過長的文本。

然而，會議中也指出了這種做法的潛在問題：如果切分方式過於隨機（例如僅按句數切分），可能會導致語意被切斷，讓模型無法掌握完整的意義。

來源如下：
*   **meeting 0318 / SPEAKER_01**: 提到一篇2024年論文的做法是「把一個長文直接把它切切切切切，切成一個 chunks，然後每一個 agent 他是負責一個 chunk 的 summary」。
*   **meeting 0318 / SPEAKER_01**: 指出這種隨機切分的缺點：「他們的切分方式很 random，就是直接說 size 幾句切下去、幾句切下去，所以有些可能是斷掉了。所以這個 agent 可能看到某一句話的一半，下一個 agent 看到某一句話下面一半，那根本就抓不起來人們的意思。」
